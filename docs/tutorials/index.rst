Tutorials
=========

Complete worked examples, each building on :doc:`../getting_started/quickstart`.

:doc:`wbb_stationary`
   Run a week of hourly footprints for a rooftop tower and make an average
   footprint map.

:doc:`flux_inversion`
   Combine footprints with emissions to model the concentrations a tower
   should have seen, and compare with observations.

:doc:`hpc_slurm`
   Take a project from your computer to a Slurm cluster to run thousands of
   simulations.

More tutorials, including satellite and column measurements, will be added as
those parts of PYSTILT settle. Until then, see :doc:`../advanced/observations`.
