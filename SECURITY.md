# Security policy

## Supported versions

Only the latest release of PYSTILT gets security fixes.

## Reporting a vulnerability

Please report a vulnerability privately, not in a public issue. Use the
repository's **Security** tab, then **Report a vulnerability**
(<https://github.com/jmineau/PYSTILT/security/advisories/new>).

Include what you found, how to reproduce it, and the version you used. You
can expect a first reply within a week. If the report holds, we will fix it in
a new release and credit you in the release notes unless you prefer not to be
named.
