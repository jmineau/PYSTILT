Core Objects#

The project, its receptors, the simulations it runs, and their outputs.

One receptor, without a project#

run_trajectories() runs the transport model for one receptor and returns its particles, and calc_footprint() makes a footprint from them. A project runs the same two steps for each of its receptors and stores the results.

particles = stilt.run_trajectories(receptor, met, n_hours=-24, numpar=200)
foot = stilt.calc_footprint(particles, receptor, grid)

run_trajectories

Run the transport model for one receptor and return its particles.

calc_footprint

Calculate a footprint from particles, as STILT-R's calc_footprint does.

Project interface#

Project

A STILT project: receptors, settings, and the simulations they define.

Receptor objects#

Receptor

Base class of the receptor types.

PointReceptor

Receptor that releases particles from one point.

ColumnReceptor

Receptor that releases particles evenly along a vertical line.

MultiPointReceptor

Receptor that releases particles from several points at once.

read_receptors

Read receptors from a CSV file.

receptors.write_receptors

Write receptors to a CSV file that read_receptors() reads, and return its path.

receptors.receptors_to_frame

Return receptors as one table with a row per release point.

receptors.receptors_from_frame

Check a table with a row per release point and build its receptors.

receptors.parse_receptor_id

Split a receptor id into its release time and location id.

Simulation objects#

A Variant is one variant of a project, resolved: its configs, its met, the transport model build, and the hashes that find its results. project.variants holds them, and ProjectConfig.resolve() makes them from a config.

Simulation

One receptor run under one variant, as one realization of an ensemble or alone.

config.Variant

One variant, resolved: its configs, its met, the model build, and its hashes.

Settings and their hashes#

stilt.identity records what a result was made with, as each output folder’s _settings.yaml holds it, and hashes it. A stored record is read back through the current config classes, so a setting added since, with a default, still matches.

identity.run_settings

Return the settings that identify a run, in canonical form.

identity.read_run_settings

Return the run settings a _settings.yaml records, read through the current classes.

identity.transport_from_settings

Return the transport model's config a run settings record holds.

identity.footprint_settings

Return the settings that identify a footprint, besides its particles, in canonical form.

identity.read_footprint_settings

Return the footprint config and geometry hash that footprint_settings() recorded.

identity.footprint_hash

Return the hash of footprints with settings, made from the particles hashed particles_hash.

identity.settings_hash

Return the SHA-256 hex digest of settings.

transport.ModelInfo

The transport model build a run was made with, recorded in the run's settings.

Particles and footprints#

A simulation’s particles are a pandas DataFrame and its footprint an xarray DataArray. PYSTILT’s methods on them are under .stilt (ParticlesAccessor, FootprintAccessor). The functions below read and write particle and footprint files without a project.

read_particles

Read a particle file.

particles.particles_metadata

Return the receptor, run settings, and met files a particle file records.

particles.write_particles

Write a particle table to a Parquet file that read_particles() reads alone.

read_footprint

Read a footprint file, NetCDF or the Parquet files PYSTILT stores.

footprint.open_footprints

Open stored footprints as one dataset, stacked on the hour from each receptor's time.

particles.ParticlesAccessor

PYSTILT methods on a particle table, as particles.stilt.

footprint.FootprintAccessor

PYSTILT methods on a footprint, as foot.stilt.

What the particles give beyond the footprint#

The background mole fraction at a receptor, from a field sampled where the particles end (Background), and the transport error of the modelled enhancement, from a wind-error variant (Transport Error). With a project they are sim.background(field) and sim.transport_error(error_sim, flux). Both weight the particles the way the footprint does.

particles.background

Return the background mole fraction at a receptor.

particles.Background

Background at a receptor, returned by background().

particles.transport_error

Return the transport-error variance of a modeled enhancement (Lin and Gerbig, 2005).

particles.TransportError

Transport error of a modeled enhancement, returned by transport_error().

Simulation tables#

project.receptors is a pandas DataFrame with one row per receptor, and project.simulations one with one row per simulation. Select rows as in pandas, then pass the selection to the project’s status(), incomplete(), particles(), footprints(), or jacobian().

sims = project.simulations
wbb = sims[(sims.variant == "hrrr") & (sims.site == "WBB")]
feet = project.footprints(wbb)

Spatial geometries#

The cells foot.stilt.aggregate sums a footprint into, such as polygons, hexagons, windows around point sources, or groups of grid cells. A Grid works as well. It is documented under Configuration.

Mesh

Polygon cells with ids, the most general geometry.

Zones

Regions made by merging the cells of a Grid or Mesh.

footprint.Geometry

Represent a union type

stilt.footprint also has the helpers that compute how much of each footprint cell falls in each target cell. These overlap weights are cached, so each geometry’s weights are computed once per footprint grid. stilt.spatial has the CRS helpers.

footprint.overlap_weights

Return the fraction of each raster cell inside each geometry cell.

footprint.check_resolution

Warn when the raster is too coarse to resolve the smallest target cell.

spatial.same_crs

Return whether two CRS strings describe the same CRS, however they are spelled.

spatial.is_longlat

Return whether crs is geographic (longitude/latitude degrees).

spatial.horizontal_dims

Return the names of the horizontal dimensions, (y_dim, x_dim).

Sampling fields#

stilt.sampling looks up a gridded field at points: a surface flux under a footprint or along particle paths (foot.stilt.enhancement, particles.stilt.enhancement), or a mole-fraction field at particle endpoints (stilt.particles.background()).

sampling.sample_field

Return the field's value in the cell nearest each point.

sampling.vertical_dim

Return the name of a field's vertical dimension.

sampling.nearest_cell

Return the index of the cell nearest each value, or -1 outside the cells.
