Execution#

Most users only need project.run(), project.submit(), or stilt run (Running). The functions below do the work underneath.

  • run() is what project.run() calls. It finds the receptors with missing results, runs them, and waits until they finish. task=(i, n) runs share i of n here (task_share()), which is what stilt run --task i/n does.

  • submit() is what project.submit() calls. It writes a job array script (job_script()) whose tasks each run stilt run --task, submits it with sbatch, and returns the job id at once.

  • run_particles() runs the transport model for one Simulation and writes its particles and log.

  • make_footprint() makes the footprint from those particles and writes it.

  • run_receptor() runs every variant of one receptor, skipping what exists. Variants that share particles run the transport model once and make their footprints from the particles in memory. A failure is recorded with the simulation (stilt.Simulation.failure). Workers are always handed receptors.

  • run_receptors() runs a list of receptors, in this process or in a process pool.

On Slurm each task of the job array runs one share of the receptors (task_share()) with stilt run --task. A local run happens in this process. A program that starts the tasks itself, on another scheduler, writes pending() to the receptors.txt each task reads (stilt run --receptors); wait() waits for a Slurm job array by its id.

Running#

stilt.execution.run

Run every simulation of a project that has not finished, and wait for it.

stilt.execution.submit

Submit every simulation of a project that has not finished to Slurm.

stilt.execution.pending

Return the ids of the receptors a run would run, each once, in project order.

stilt.execution.wait

Wait until every task of a Slurm job array has ended, and return how each ended.

stilt.execution.task_share

Return task task's share of receptor_ids, split n_tasks ways.

Workers#

Internal: importable from their modules, and free to change.

stilt.execution.runner.resolve_compute_root

Return the compute root of project: the directory its workdirs are made in.

stilt.execution.worker.run_particles

Run the transport model for a simulation and write its particles to the output directory.

stilt.execution.worker.make_footprint

Calculate a simulation's footprint from particles and write it to its folder.

stilt.execution.worker.run_receptor

Run every simulation of one receptor, and return what did not complete.

stilt.execution.worker.run_receptors

Run a list of receptors, in this process or in a process pool.

Slurm job arrays#

stilt.execution.job_script

Return the sbatch script of a job array whose tasks each run a share of the receptors.

Transport model#

The worker runs a simulation through the transport model its settings name. HYSPLIT is the one built in, and CONTRIBUTING describes how to add another. A model fails a run that its meteorology does not cover, as MET_COVERAGE. Particles that all leave the met’s domain before the end of the run are a complete run.

stilt.transport.TransportModel

A transport model that follows particles from a receptor.

stilt.transport.BatchedTransportModel

A transport model that runs many receptors in one call, such as an emulator on a GPU.

stilt.transport.TransportConfig

The base of every transport model's config.

stilt.transport.ModelRun

What one model run produced.

stilt.transport.get_model

Return the transport model name names.

stilt.transport.run_model

Run the transport model called name for one receptor, and finish its particles.

stilt.transport.run_model_many

Run a batched transport model once for many receptors, and finish each one's particles.

stilt.transport.hysplit.HysplitModel

HYSPLIT as a transport model, the object get_model("hysplit") returns.
